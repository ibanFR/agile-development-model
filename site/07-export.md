## Export the views within a Structurizr workspace

Requirements for exporting diagrams:

- Install [Structurizr CLI](https://docs.structurizr.com/cli/installation)

```shell
./structurizr.sh export -workspace /Users/ivan/git/ibanFR/agile-development-model/workspace.dsl -format plantuml -output diagrams
```

[Import mermaid diagrams into draw.io](https://www.drawio.com/blog/mermaid-diagrams)
